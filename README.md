# sistema-ventas-inventario-php
Sistema de ventas, inventario y facturación.

Este es un sistema desarrollado en PHP y MySQL, diseñado para pequeños negocios que necesitan digitalizar su control de inventario y ventas.

Tecnologías utilizadas:

PHP

MySQL

HTML, CSS, JavaScript

Funcionalidades principales:

Control de inventario.

Generación de tickets y facturas.

Sistema de roles (Administrador y Usuario).

Gestión de clientes y productos.

Para ejecutarlo, importar la base de datos en XAMPP y configurar el archivo de conexión.
